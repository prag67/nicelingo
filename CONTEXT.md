# Nicelingo Ubiquitous Language

## Language

A course language the learner can study. Each has its own name ("Español"),
an English name ("Spanish"), and a two-letter code (`es`). Today: English,
Spanish, French, German (full courses), Mandarin and Thai (Level 1 only).

## Availability

Whether a Language appears in the picker, derived from lesson data:

- **complete** — all 240 lessons have content and audio.
- **partial** — a real course, but only some levels (Mandarin, Thai:
  Level 1, 48 lessons each). Shown with a "Level 1 only" tag, never
  hidden.
- **hidden** — not shown anywhere (reserved for future languages).

## Lesson count

The number of lessons a Language offers. Always counted from the lessons
record, never stored or hard-coded.

## Subscription coverage

What a paid subscription unlocks. The paywall gates every lesson except
Unit 1 (lessons 001-004) in every visible Language, so coverage is:
**every lesson in every picker Language**. Unit 1 is free in every
Language with or without a subscription.
